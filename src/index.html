Condicionales en JavaScript

Aprende a controlar el flujo de tu código con decisiones inteligentes

¿Qué son los condicionales?

Los condicionales son instrucciones que nos permiten ejecutar diferentes bloques de código según se cumplan o no ciertas condiciones. Son como los "cruces de caminos" en tu programa.

¿Para qué usamos condicionales?

Tomar decisiones

Ejecutar diferentes bloques de código según las condiciones que estableces

Controlar el flujo

Dirigir el camino que seguirá tu programa, como semáforos en una carretera

Validar datos

Comprobar si los datos cumplen con ciertos requisitos antes de procesarlos

Manejar casos

Responder de manera diferente a distintas situaciones en tu programa

¿Cómo funcionan los condicionales?

if (true) {
          console.log("Esta parte se ejecuta");
      } else {

      }

Tipos de Condicionales

if-else: Decisiones Simples

La estructura más básica. Ejecuta un bloque si la condición es verdadera y otro si es falsa.

🔑 Usa if para la condición principal
🔑 La parte else es opcional
🔑 Siempre usa llaves {} para mayor claridad
if-else 
    let edad = 20;
    
    if (edad >= 18) {
      console.log("Eres mayor de edad. Puedes conducir.");
    } else {
      console.log("Eres menor de edad. No puedes conducir.");
    }
20

No ejecutado aún

else if: Múltiples Condiciones

Permite evaluar varias condiciones en secuencia. Útil cuando tienes múltiples casos posibles.

🔑 Puedes tener tantos else if como necesites
🔑 Se evalúan en el orden en que aparecen
🔑 Usa else al final para el caso por defecto
else if 
    let nota = 85;
    
    if (nota >= 90) {
      console.log("Sobresaliente");
    } else if (nota >= 80) {
      console.log("Notable");
    } else if (nota >= 70) {
      console.log("Bien");
    } else if (nota >= 60) {
      console.log("Suficiente");
    } else {
      console.log("Necesita mejorar");
    }
85
Resultado:
No ejecutado aún

Operador Ternario: Condicional Compacto

Un atajo para if-else en una sola línea. Perfecto para asignaciones condicionales sencillas.

🔑 Sintaxis: condición ? valorSiVerdadero : valorSiFalso
🔑 Ideal para casos simples y concisos
🔑 Evita usarlo con lógica compleja
Operador Ternario 
                  let edad = 20;
                  
                  // Usando el operador ternario
                  let mensaje = edad >= 18 
                    ? "Eres mayor de edad" 
                    : "Eres menor de edad";
                  
                  console.log(mensaje);

Switch: Múltiples Casos Específicos

Ideal cuando necesitas comparar una variable con valores específicos. Más legible que múltiples if-else.

⚠️ No olvides el break al final de cada caso
🔑 Usa default para el caso por defecto
🔑 Comparación estricta (===) con el valor evaluado
Switch 
                  let diaSemana = 3; // 1-7 representa lunes a domingo
                  
                  switch (diaSemana) {
                    case 1:
                      console.log("Hoy es Lunes");
                      break;
                    case 2:
                      console.log("Hoy es Martes");
                      break;
                    case 3:
                      console.log("Hoy es Miércoles");
                      break;
                    case 4:
                      console.log("Hoy es Jueves");
                      break;
                    case 5:
                      console.log("Hoy es Viernes");
                      break;
                    case 6:
                    case 7:
                      console.log("¡Es fin de semana!");
                      break;
                    default:
                      console.log("Día no válido");
                  }

Comparativa de Sintaxis

Hay varias formas de escribir condicionales en JavaScript. Elige la adecuada según tu caso.

if-else
if (condición) {
                  // código
                } else {
                  // código
                }
  • Decisiones simples
  • Bloques grandes de código
  • Usar siempre { } aunque sea una línea
else-if
if (cond1) {
                  // código
                } else if (cond2) {
                  // código
                } else {
                  // código
                }
  • Múltiples condiciones secuenciales
  • Rangos de valores
  • Se evalúan en orden
  • Solo se ejecuta el primer bloque que cumpla
Ternario
cond ? valorTrue : valorFalse
  • Asignaciones condicionales
  • Condicionales de una línea
  • Usar solo para casos simples
  • Evitar anidar ternarios
switch
switch (valor) {
                  case x:
                    // código
                    break;
                  default:
                    // código
                }
  • Muchos casos específicos
  • Valores discretos
  • No olvidar break en cada caso
  • Usa default para casos no especificados
Errores Comunes y Buenas Prácticas

Errores Comunes

Confundir = con == o ===

              // ❌ ERROR: Asignación en vez de comparación
              if (variable = true) {
                // Este código SIEMPRE se ejecutará
                // porque estás asignando true a variable
              }
              // ✅ CORRECTO: Comparación
              if (variable === true) {
                // Este código se ejecuta solo si variable es true
              }

El operador = es para asignar valores, mientras que == y === son para comparar.

Olvidar el break en switch

              // ❌ ERROR: Sin break
              switch (valor) {
                case 1:
                  console.log("uno");
                case 2:
                  console.log("dos");  // Se ejecutará para valor=1 también
              }
              // ✅ CORRECTO: Con break
              switch (valor) {
                case 1:
                  console.log("uno");
                  break;
                case 2:
                  console.log("dos");
                  break;
              }

Sin break, el código continúa ejecutándose en los siguientes casos, causando comportamientos inesperados.

Anidar demasiados condicionales

              // ❌ ERROR: Demasiados niveles anidados
              if (condicion1) {
                if (condicion2) {
                  if (condicion3) {
                    if (condicion4) {
                      // Código difícil de seguir
                    }
                  }
                }
              }
              // ✅ CORRECTO: Comprobaciones combinadas
              if (condicion1 && condicion2 && condicion3 && condicion4) {
                // Código más limpio y fácil de entender
              }

Demasiados niveles anidados hacen que el código sea difícil de leer y mantener.

Buenas Prácticas

Usar comparación estricta (===)

              // Comparación estricta (===)
              if (edad === 18) {
                // Verifica valor Y tipo de dato
              }

La comparación estricta (===) verifica que tanto el valor como el tipo de dato sean iguales, evitando conversiones automáticas que pueden causar errores.

Mantener las condiciones simples

              // Extraer condiciones complejas en variables
              const esAdulto = edad >= 18;
              const tieneLicencia = tipoLicencia !== "ninguna";
              
              if (esAdulto && tieneLicencia) {
                // Código más legible
              }

Las condiciones complejas pueden extraerse a variables con nombres descriptivos para mejorar la legibilidad.

Usar llaves incluso para una sola línea

              // Siempre usar llaves { }
              if (condicion) {
                ejecutarFuncion();
              }
              
              // En lugar de:
              // if (condicion) ejecutarFuncion();

Las llaves hacen el código más consistente y previenen errores al añadir más líneas posteriormente.

Elegir la estructura adecuada

              // Para asignaciones simples: ternario
              const mensaje = edad >= 18 ? "Adulto" : "Menor";
              
              // Para múltiples valores específicos: switch
              switch (diaSemana) {
                case 1: // código
              }
              
              // Para rangos o condiciones complejas: if-else
              if (temperatura > 30) {
                // código
              }

Cada estructura tiene sus usos ideales. Elige la que mejor se adapte a tu caso específico.

Mini-Juego: Elige el Condicional Correcto

Escenario 1:

Necesitas verificar si un usuario es mayor de edad (18 años o más) para permitirle acceder a cierto contenido.

¡Correcto! Un simple if-else es perfecto para una comparación de valor.

            if (edad >= 18) {
              permitirAcceso();
            } else {
              denegarAcceso();
            }

No es la mejor opción. Un simple if-else es más adecuado para esta comparación.

Escenario 2:

Tienes una variable 'diaSemana' (1-7) y quieres mostrar un mensaje diferente para cada día.

¡Correcto! Switch es ideal para manejar múltiples valores específicos de una variable.

            switch (diaSemana) {
              case 1:
                console.log("Lunes");
                break;
              case 2:
                console.log("Martes");
                break;
              // etc...
            }

No es la mejor opción. Switch es ideal para evaluar una variable contra múltiples valores específicos.

Escenario 3:

Necesitas asignar una de dos cadenas a una variable, según una condición simple.

¡Correcto! El operador ternario es ideal para asignaciones condicionales simples.

            const mensaje = edad >= 18 
              ? "Mayor de edad" 
              : "Menor de edad";

El operador ternario sería más conciso para una simple asignación condicional.
